# journal/ — 일별 증류본

`scripts/nightly-distill.sh` 가 매일 밤 그날의 `chat/YYYY-MM-DD.jsonl` 과 수집기 데이터를 읽어
`journal/YYYY-MM-DD.md` 한 장으로 압축한다. 비서는 과거를 물으면 이 디렉토리를 Grep 한다.

틀 (증류 프롬프트가 이 순서로 쓴다):

```markdown
# 2026-01-15 (수)

## 한 줄 요약
## 결정·약속
## 새로 알게 된 사실 (어느 파일에 반영했는지)
## 열린 고리 변화
## 건강·일정 (수집기 데이터가 있을 때만)
```

예시 한 장은 `2026-01-15.md` 참고. 손으로 고쳐도 된다 — 다음 증류가 덮어쓰지 않고 같은 날짜 파일이 있으면 건너뛴다.

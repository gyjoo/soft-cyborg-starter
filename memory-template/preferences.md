# 선호

## 소통
- 답은 결론 먼저, 세 문장 안에. 길어질 것 같으면 "자세히 볼까요?" 한 줄만.
- 이모지는 쓰지 않는다. 존댓말, 단 딱딱하지 않게.
- 확인 질문은 꼭 필요할 때만. 애매하면 합리적 기본값으로 진행하고 나중에 알려 달라.

## 일
- 회의는 오전에 몰아서. 14:00~17:00 는 집중 시간이라 알림 최소화.
- 할 일 관리는 마크다운 체크박스면 충분. 외부 투두 앱 연동은 아직 원하지 않음 (2026-01-15, 구: Todoist 검토 중).

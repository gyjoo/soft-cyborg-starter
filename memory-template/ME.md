# 나 (예시 — 전부 가상의 인물)

- 이름: 김하늘 (Haneul Kim). 1991년생. 서울 마포구 거주.
- 직업: 중소 커머스 회사 데이터 엔지니어. 주 스택은 Python·dbt·BigQuery.
- 가족: 배우자 이서준, 반려견 두부(말티즈, 4살).
- 건강: 러닝 주 3회 목표. 왼쪽 무릎이 약해 10km 넘기지 않음. 카페인은 오후 2시 이후 금지.
- 하루 리듬: 06:30 기상, 09:30~18:30 근무(수요일 재택), 23:00 취침 목표.
- 올해 목표: 하프 마라톤 완주, 사이드 프로젝트 하나를 공개 배포, 책 24권.
- 통화 단위는 원화. 날짜는 `YYYY-MM-DD`, 시간은 24시간제로 말해 달라.

비서가 알아둘 것: 아침 브리핑은 07:00 슬랙 DM 으로. 저녁에는 "오늘 뭐 했지" 한 줄 회고를 물어보는 걸 좋아함.
